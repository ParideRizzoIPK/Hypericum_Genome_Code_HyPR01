# 06 — Organellar Genomes

Assembly and annotation of the chloroplast and mitochondrial genomes,
independently of the nuclear genome pipeline above.

- `Assembly/` — TIPPo and HiMT organellar assembly (two independent methods, for cross-validation), plus the scripts that build their comparison summary tables.
- `Annotation/Chloroplast/` — rotating the curated chloroplast genome to the conventional start position.
- `Annotation/Mitochondria/` — OGDraw/pyCirclize rendering of the mitochondrial gene maps.
